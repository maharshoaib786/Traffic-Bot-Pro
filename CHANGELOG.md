# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-10-17

### Added
- Initial public release of the Traffic Bot Pro Toolkit package.
- Asynchronous traffic simulation engine with proxy and user-agent rotation.
- CLI for running, scheduling, and generating campaign configurations.
- Metrics collection utilities and sample campaign configuration.
- GitHub Actions workflow for tagged release automation.
